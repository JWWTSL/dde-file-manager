# AT 用例覆盖率报告

## 1. 数据源与统计口径

- 原始用例：`/home/tsl/Documents/youqu/统信桌面操作系统 V25-用例.xlsx` 的 `用例` sheet。
- 仓库内未找到 `tests/at/cases_raw.yaml` 或 `tests/at/casefile`。
- AT 用例：`tests/at/yaml/**/*.suite.yaml` 中 `suites` 下的 case。
- 原始 ID 提取优先级：`vars.xlsx_id`、description 中的来源编号、`case_<七位ID>` 前缀。
- 覆盖按用户确认口径统计：可自动化成果中已跑通并登记的原始用例计入覆盖。
- 同一原始 ID 被多条 suite case 引用时只计一次；一条 suite case 明确覆盖多个原始 ID 时按原始 ID 分别累计。

### 3.1 重复映射说明

- 1512 是实际文件中的 suite case 数，不做去重。
- 137 个原始 ID 被多条 suite case 引用，若只按原始 ID 合并会减少 178 条映射。
- 105 组属于同一原始 ID 且同名的疑似重复，涉及约 106 条额外 suite case。
- 重复引用可能是场景拆分，也可能是不同批次重复生成，不能仅凭 ID 自动删除。
- 报告中的覆盖数始终按原始 ID 去重，因此重复 suite case 不会抬高 569 条覆盖。

### 3.1.1 已清理的无效用例（2026-09-23 审计）

- 删除 35 条弱重复 case：同一原始 ID 下旧弱 case（无 UI 操作或仅 `PASS_` 标记断言）与新强 case 并存，删弱留强，删除后逐一复核 35 个原始 ID 均仍有强 case 覆盖。
- 修复 `xlsx增量youqu.suite.yaml` 中 10 条 description 的用例编号错误（误写为 1873487，`vars.xlsx_id` 本就正确，不影响统计）。
- 保留 61 条唯一弱覆盖 case（其原始 ID 仅由该弱 case 覆盖，删除会导致覆盖率下降）。

### 3.2 第二批 25 条说明

`xlsx严格补充第二批.suite.yaml` 中 25 条 case 已按当前成果口径计入转换覆盖。它们多使用文件系统结果和 `PASS_<ID>` 标记进行断言，属于质量偏弱的覆盖形态；后续可作为质量提升项优化，但不影响本次主统计口径。
