## 1. 数据源与统计口径

- 原始用例：`/home/tsl/Documents/youqu/统信桌面操作系统 V25-用例.xlsx` 的 `用例` sheet，基线 2400 条（已由 xlsx 行数和唯一用例编号复核）。

### 3.1 重复映射说明

- 1512 为实际 suite case 数，不做去重。
- 137 个原始 ID 被多条 suite case 引用，若按原始 ID 合并将减少 178 条映射（excess 178）。
- 105 组为同一原始 ID 且同名的映射，涉及约 106 条额外 suite case；经逐一核对属场景拆分（不同入口/不同断言/不同前置数据），判定合理保留。
- 一条 suite case 覆盖多个原始 ID 的情况经扫描为 0 条；所有多映射均为多条 case 指向同一原始 ID。
- 覆盖数始终按原始 ID 去重，重复 suite case 不会抬高 569 条覆盖。

| 审计项 | 数量 | 处理结果 |
|---|---:|---|
| 弱重复 case（同原始 ID 下旧弱+新强并存） | 35 | 已删除弱者，35 个原始 ID 复核均仍有强 case 覆盖 |
| description 用例编号错误（误写为 1873487） | 10 | 已修复文本；`vars.xlsx_id` 本就正确，统计未受影响 |

- 强 case 定义：含真实 UI 操作步骤（element_action/keyboard/mouse 等）且有具体元素断言。
- 弱 case 定义：无 UI 操作或仅 `PASS_<ID>` 标记/shell 断言。
- 清理结果：1547 → 1512 条，可自动化覆盖率保持 100.00% 无损失；Gate 4/5 校验通过。
